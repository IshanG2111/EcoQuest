# Screenshots

This directory holds high-resolution screenshots used in the `README.md` and documentation.

## Convention

| Filename | Depicts |
|---|---|
| `01_desktop_os.png` | The full EcoQuest Retro Edu-OS desktop workspace |
| `02_ecograph_galaxy.png` | The EcoGraph 3D/2D ecological knowledge galaxy |
| `03_passport_portal.png` | The Planetary Passport login portal with hologram themes |
| `04_arcade_vault.png` | The Planetary Arcade Vault & game roster |
| `05_citizen_dashboard.png` | The Citizen Dashboard with XP and 3D passport |
| `06_quizzes.png` | The Ecological Knowledge Challenge Suite |
| `07_ecograph_inspector.png` | Node inspector drawer showing species data |

## Taking Screenshots

- Resolution: **1280×720** (standard HD)
- Format: **PNG** (lossless)
- Run `npm run dev` then capture each route

> Screenshots are committed to this repo and referenced directly in `README.md`.
